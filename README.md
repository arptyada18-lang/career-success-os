# Career & Success OS

A personal career, productivity, learning and success operating system built with HTML, CSS and vanilla JavaScript.

## Core modules
- Command Center dashboard
- Today / task manager
- Career goals
- Skills tracker
- Project Launchpad
- Learning roadmap
- College study tracker
- Internship pipeline
- Freelance Client CRM
- Creator content tracker
- LinkedIn growth tracker
- Habit streaks
- Achievements timeline
- Career analytics
- Weekly & monthly reviews
- Profile/settings
- XP + levels + Career Score
- LocalStorage persistence
- JSON backup export/import
- Responsive mobile navigation

## Cost model
This version has no paid API, paid database or paid backend dependency. Data is stored locally in the browser.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser LocalStorage
